# Twitch Clip Bot 🤖🎬

Telegram-бот, который создаёт вертикальные клипы (9:16) из стримов Twitch по команде `!clip`.

## Возможности

- 🔗 Привязка Twitch-ника к Telegram-аккаунту (`/start` → инлайн-кнопка «Привязать Twitch»).
- 👂 Слушает Twitch-чат стримера (IRC через websocket) и реагирует на команду `!clip`.
- 🎬 Создаёт клип через Twitch Helix API, ждёт обработки и присылает ссылку.
- 📱 Приводит клип к вертикальному формату 1080×1920 через `ffmpeg` (размытый фон + центрированное видео).
- 🎛 Инлайн-кнопки под клипом: «Скачать», «Открыть на Twitch», «Повторить».
- 🛡 Все клипы также уходят администратору (`ADMIN_ID`).
- 💾 SQLite хранит связки `telegram_id ↔ twitch_nick` и историю клипов.
